# WolfNote 最终版（移动端优化）

## 玩家模式
- 针对手机和平板重新设计：底部三栏导航「记录 / 号码 / 记录本」
- 单屏快速记录：发言人、行为、目标 + 大记录按钮
- 第1天至第20天切换，支持下一天快捷键
- 淘汰玩家整卡变灰，但身份仍可修改
- 号码卡可快速切换好人 / 狼 / 观察、身份、淘汰状态
- 记录本支持按玩家和天数筛选
- 最近5条记录直接显示在快速记录页
- 数据只保存于当前浏览器 localStorage

## 法官模式
保留现有单阶段法官流程及 9/10/12/13 人板子。
