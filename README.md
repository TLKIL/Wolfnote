# WolfNote v2

狼人杀玩家记录 + 法官控场工具。

## 两种模式
- 玩家模式：进入前选择自己的号码，记录发言关系、金水、查杀、站边、票型和号码判断。
- 法官模式：设置玩家身份、存活状态、警长、夜间/白天事件、放逐与时间线。

## 数据隔离
所有数据使用浏览器 localStorage 保存：
- 不同用户、不同设备、不同浏览器互不共享。
- 玩家数据与法官数据使用不同存储键，也不会互相覆盖。
- 不需要服务器或账号。
